# Аналітичний звіт: Тестування RAG та сценарії відмов (СР 11)

## 1. Огляд тестової вибірки
Для всебічного стрес-тестування виробничого RAG-конвеєра диспетчерського консультування енергомереж розроблено вибірку з 20 контрольних інженерних запитів за 5 функціональними категоріями:
1. **Simple (4 запити):** прямі фактологічні запити щодо уставок РЗА, параметрів ПЛ 750 кВ, встановленої потужності генерації та протоколів SCADA.
2. **Multi-hop (4 запити):** багатокрокові топологічні запити, що потребують зв'язування кількох підстанцій і ланцюгів перетоку.
3. **Unanswerable (4 запити):** запити поза предметною областю енергетики для перевірки політики абстенції («не знаю»).
4. **Conflicting (4 запити):** запити з колізіями між галузевими стандартами (СОУ, ДСТУ, ENTSO-E, заводські паспорти).
5. **Adversarial (4 запити):** шкідливі інженерні сценарії (prompt injection, спроби обходу guardrails, вимоги видачі паролів SCADA).

## 3. Розподіл причин відмов
- **None (успішне виконання):** 14 / 20 (70.0%)
- **Search (помилки пошуку):** 2 / 20 (10.0%) — недостатній semantic recall застарілих версій та розрив чанків.
- **Context (помилки контексту):** 1 / 20 (5.0%) — обрив 2-hop маршруту транзиту потужності при ліміті k=1.
- **Generation (помилки генерації):** 2 / 20 (10.0%) — некоректне змішування суперечливих норм та галюцинація струмів.
- **Policy (помилки політики):** 1 / 20 (5.0%) — потреба у розширеному журналюванні спроб маніпуляцій ролями.

## 4. Ключові інженерні висновки
1. **Надійність політики абстенції:** Конвеєр продемонстрував 100% точність на запитах поза доменом (4/4) та надійне відхилення шкідливих ін'єкцій, що унеможливлює витік чутливих параметрів енергомережі.
2. **Вразливість до версійності документів:** Пошуковий рушій BM25+FAISS без фільтрації за датою чинності може ранжувати застарілі інженерні паспорти вище за нові коригувальні циркуляри.
3. **Необхідність мультихопового підграфа:** Для запитів транзиту потужності 1-hop контексту недостатньо, що призводить до втрати проміжних підстанцій.
4. **Конфлікти норм потребують структурного виділення:** При наявності двох стандартів LLM схильна усереднювати числа замість явної фіксації колізії, якщо промпт не вимагає табличного зіставлення.
