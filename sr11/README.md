## Опис проєкту
Роботу присвячено комплексному тестуванню та аналізу відмов виробничого RAG-конвеєра диспетчерського управління енергосистеми.
Сформовано вибірку з 20 контрольних інженерних запитів за 5 категоріями (Simple, Multi-hop, Unanswerable, Conflicting, Adversarial).
Здійснено класифікацію помилок за чотирма класичними типами (пошук, контекст, генерація, політика), обчислено метрики Faithfulness через LLM-as-a-Judge з ручною верифікацією та розроблено пріоритизований план виправлень (P0–P3).

## Структура репозиторію
```
├── data/
│   ├── corpus.jsonl             # Корпус нормативної документації енергомереж (225 чанків)
│   ├── nodes.csv                # Топологічні вузли енергомережі (146 вузлів)
│   └── relationships.csv        # Зв'язки ліній та приєднань (280 зв'язків)
├── eval/
│   ├── rag_failure_cases.jsonl  # Повний датасет 20 тестів із класифікацією
│   └── failure_summary.csv      # Зведена таблиця результатів та причин
├── docs/
│   ├── failure_analysis.md      # Детальний інженерний звіт класифікації відмов
│   └── remediation_plan.md      # План усунення дефектів із цільовими метриками
├── claims/
│   └── claims.csv               # Таблиця тверджень за протоколом LLM-експерт
├── llm_log/
│   └── llm_judge_log.json       # Журнал автоматичного суддівства та ручної верифікації
├── src/
│   ├── test_failures.py         # Тестовий раннер RAG
│   └── generate_proof_images.py # Генератор графіків та скріншотів
├── terminal_failures_proof.png  # Консольне підтвердження запуску
├── failure_distribution_chart.png # Діаграма розподілу відмов
├── compile.bat                  # Скрипт компіляції звіту tectonic
└── Гріджак_Олександр_СР11_СЗУЗ.tex # Вихідний код звіту в LaTeX
```

## Інструкція відтворення
1. Встановлення залежностей:
   ```bash
   pip install -r ../lab/requirements.txt
   ```
2. Запуск тестового раннера відмов:
   ```bash
   python src/test_failures.py
   ```
3. Генерація ілюстрацій:
   ```bash
   python src/generate_proof_images.py
   ```
4. Компіляція звіту в PDF:
   ```cmd
   compile.bat
   ```
