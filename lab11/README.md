## 1. Загальний опис проєкту
У роботі реалізовано повноцінний виробничий конвеєр інтелектуального консультування інженерів-диспетчерів НЕК «Укренерго». Система поєднує:
- **Гібридний семантичний та лексичний пошук (BM25 Okapi + FAISS Dense HNSW)** за корпусом із 225 нормативних чанків технічної документації 750/330 кВ;
- **Топологічний підграф енергомережі (GraphRAG)** із бази знань Neo4j (146 вузлів, 280 зв'язків), що забезпечує зв'язне обґрунтування маршрутів перетоків потужності;
- **Суворе цитування першоджерел у форматі `[CHK-XXXX]`** та автоматичну валідацію посилань;
- **Політику абстенції («не знаю»)** для гарантованого відсікання галюцинацій на запитах поза доменом;
- **Захист від prompt injection** та контроль доступу на рівні ролей (**RBAC: analyst vs engineer**);
- **REST API на базі FastAPI** з ендпоінтами `/ask`, `/health`, `/sources/{id}`, валідацією Pydantic та лімітами швидкості (Rate Limiting).

## 3. Інструкція із запуску

### Встановлення залежностей:
```bash
pip install -r requirements.txt
```

### Автоматизований прогін усіх результатів (1–5) та генерація скріншотів:
```bash
python scripts/run_lab11.py --all
```

### Запуск виробничого REST API:
```bash
python api/main.py
# Або через Uvicorn:
uvicorn api.main:app --host 127.0.0.1 --port 8000
```
Інтерактивна документація доступна за посиланням: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

### Компіляція звіту в PDF:
```bash
./compile.bat
```
Звіт компілюється в папку `latex_pdf/Гріджак_Олександр_ЛР11_СЗУЗ.pdf`.
