## 1. Структура проєкту
```text
lab13/
├── data/
│   ├── raw_documents.jsonl      # 20 первинних диспетчерських журналів
│   ├── gold.jsonl               # 161 еталонний факт (115 dev / 46 test)
│   ├── extractions_rules.jsonl  # Результат витягу Методу А
│   └── extractions_llm.jsonl    # Результат витягу Методу Б з provenance
├── docs/
│   ├── extraction_schema.md     # Схема сутностей і відношень, правила
│   ├── gold_card.md             # Картка набору даних, Cohen's Kappa = 1.000
│   ├── extraction_eval.md       # Оцінювання на test (P/R/F1, 10 помилок)
│   └── patterns.md              # Асоціативні правила аварійності
├── src/
│   ├── extract_rules.py         # Метод А: spaCy + regex патерни
│   ├── extract_llm.py           # Метод Б: LLM Few-Shot + схема Pydantic
│   ├── eval_extraction.py       # Метрики якості та аналіз помилок
│   ├── load_graph.py            # Нормалізація 22 сутностей і граф NetworkX
│   └── mine_patterns.py         # Пошук асоціативних правил (Support, Conf, Lift)
├── claims/
│   └── claims.csv               # Протокол верифікації тверджень LLM (V1–V4)
└── llm_log/
    └── llm_interaction_log.json # Повний журнал взаємодії з генеративною моделлю
```

---

## 2. Швидкий запуск з нуля
```bash
pip install -r requirements.txt

# 1. Запуск витягу знань правилами (Метод А)
python src/extract_rules.py

# 2. Запуск витягу знань LLM зі схемою (Метод Б)
python src/extract_llm.py

# 3. Оцінювання на test-вибірці (Precision, Recall, F1)
python src/eval_extraction.py

# 4. Нормалізація сутностей та завантаження графа знань
python src/load_graph.py

# 5. Видобування асоціативних правил та інженерна верифікація
python src/mine_patterns.py
```

---

## 3. Ключові результати
* **F1-Score:** Метод А (правила) = `0.718` (12 мс/док), Метод Б (LLM) = `0.946` (1.15 с/док).
* **Граф знань:** 80 вузлів, 161 ребро з атрибутами `doc_id`, `evidence_quote`, `timestamp`.
* **Закономірності:** 3 підтверджені фізичні закономірності аварійності (шквальний вітер, перевантаження трансформаторів, ожеледь).
