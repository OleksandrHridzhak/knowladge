## 4. Відповіді на питання для самоперевірки

1. **Чому важлива нормалізація векторів?**
   - Нормалізація векторів (L2-норма до одиничної довжини $\|v\|_2 = 1$) перетворює скалярний добуток (Inner Product) на точний еквівалент косинусної подібності. Це дозволяє використовувати максимально швидкі обчислення у FAISS без додаткових операцій ділення на добуток довжин векторів при кожному порівнянні.

2. **Коли дотреновувати модель?**
   - Дотренування (domain fine-tuning або contrastive training) необхідне у випадках, коли предметна область містить унікальні абревіатури, номенклатуру обладнання (наприклад, специфічні ГОСТ/ДСТУ маркування на зразок `3хАОДЦТН-333000`), що токенізуються базовим BPE/WordPiece на беззмістовні субтокени, або коли семантична відстань між поняттями в інженерній галузі суттєво відрізняється від загальновживаної мови.

3. **Як мова впливає на результат?**
   - Мономовні англомовні моделі зазнають катастрофічної деградації на україномовних текстах (падіння Recall@5 з 0.8667 до 0.3667) через відсутність україномовних підслів у словнику BPE: кириличні символи розбиваються на окремі байти `[UNK]` або дрібні фрагменти, що повністю руйнує контекстне представлення.

4. **Які обмеження вашого експерименту?**
   - Вибірка обмежена 225 чанками нормативно-технічної документації енергомереж України; тестування проводилося в режимі in-memory на CPU; затримка вимірювалася для чистого пошуку без урахування генеративного етапу LLM.

## 5. Інженерний висновок (Trade-off: мова, якість, затримка, вартість)
Для виробничого RAG-пайплайну в галузі енергетики оптимальним вибором за критерієм «якість / швидкість / пам'ять» є **`paraphrase-multilingual-MiniLM-L12-v2`**:
- Забезпечує високу якість (Recall@5 = 0.8667, MRR = 0.8142), поступаючись важчій моделі `multilingual-e5-base` лише 3.3%, проте працює вдвічі швидше (0.082 мс проти 0.165 мс) та займає вдвічі менше оперативної пам'яті (0.35 МБ проти 0.69 МБ);
- Повністю ліквідує мовний бар'єр, демонструючи більш ніж дворазову перевагу над англомовною baseline-моделлю `all-MiniLM-L6-v2`;
- Локальне розгортання не потребує платних хмарних API, гарантуючи нульову фінансову вартість та повну конфіденційність технічних даних енергомереж.
