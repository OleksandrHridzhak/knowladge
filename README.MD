## Структура репозиторію

Репозиторій організовано за модульною структурою навчального курсу. Кожен каталог містить вихідні коди, структуровані набори даних, запити та технічну документацію відповідно до вимог методичних вказівок:

- **`lab9/`** — **Лабораторна робота № 9:** Графова модель енергомережі в СУБД Neo4j
  - `data/` — CSV-файли топології енергомережі (`nodes.csv` — 146 вузлів, `relationships.csv` — 280 зв'язків).
  - `import/` — Cypher-скрипти створення схеми, індексів, обмежень та ідемпотентного завантаження.
  - `queries/` — Аналітичні Cypher-запити (Q1–Q8) та тестовий підграф для ручної перевірки.
  - `docs/` — Діаграма моделі графа (PDF/PNG/SVG), CQ mapping, звіти GDS та аналіз SPARQL vs Cypher.
  - `scripts/` — Python-скрипти автоматизації генерації даних, аналітики (NetworkX / Louvain / PageRank) та Text-to-Cypher валідації.
  - `tests/` — Датасет валідації Text-to-Cypher (`t2c.jsonl`).
  - `claims/` — Журнал формалізованих тверджень предметної області (`claims.csv`).
  - `llm_log/` — Протокол взаємодії з мовною моделлю (`llm_interaction_log.json`).
  - `docker-compose.yml` — Декларація контейнера Neo4j Community з плагінами APOC та GDS.
  - `requirements.txt` — Python-залежності для аналітики та автоматизації.

- **`lab10/`** — **Лабораторна робота № 10:** Векторне сховище та семантичний пошук
  - `data/` — Корпус технічної документації магістральних мереж (`corpus.jsonl` — 225 чанків).
  - `docs/` — Паспорт корпусу, аналіз стратегій чанкінгу, порівняння ембедінгів, звіт гібридного пошуку та звіт комплексного оцінювання.
  - `src/` — Модулі генерації корпусу, чанкінгу, побудови FAISS HNSW, гібридного пошуку BM25 + Dense + Rerank та оцінювання.
  - `eval/` — Золотий набір запитів (`gold.jsonl` — 45 запитів 4 категорій) та верифікація Cohen's Kappa $\kappa = 0.9048 \ge 0.82$.
  - `claims/` — Журнал верифікації технічних тверджень (`claims.csv`).
  - `llm_log/` — Протокол інженерної взаємодії з мовною моделлю (`llm_interaction_log.json`).
  - `scripts/` — Майстер-скрипт запуску повного циклу дослідження (`run_lab10.py`).
  - `requirements.txt` — Залежності (FAISS, PyTorch, Sentence-Transformers, Rank-BM25).

## Швидкий запуск

### 1. Розгортання графової бази даних (Neo4j)
Для запуску контейнера Neo4j з налаштованими портами (7474 HTTP, 7687 Bolt):
```bash
cd lab9
docker compose up -d
```

### 2. Встановлення Python-оточення
```bash
cd lab9
pip install -r requirements.txt
```

### 3. Автоматизований прогін пайплайну
```bash
python scripts/run_lab9.py
```
Скрипт згенерує топологічні дані, виконає аналітику PageRank та Louvain, проведе перевірку безпеки Text-to-Cypher та створить векторну схему графа.
