# Самостійна робота №12: Проєктування зіркової схеми

- **Студент:** Гріджак Олександр (група ФЕІ-43, ЛНУ ім. Івана Франка, ФЕКТ)
- **Курс:** «Сховища знань та управління знаннями»
- **Тематична область:** Моделювання енергомереж (Сектор: Енергетика)
- **Бізнес-процес:** Аудит надійності електропостачання та облік недовідпущеної електроенергії (ENS / SAIDI) по вузлах ОЕС України

## Артефакти самостійної роботи
- `sql/sr12_ddl.sql` - DDL зіркової схеми у DuckDB (`fact_outage_balance` + 5 вимірів: `dim_time`, `dim_grid_node`, `dim_equipment_taxonomy` із SCD Тип 2 та IRI, `dim_outage_cause`, `dim_consumer_category`).
- `sql/sr12_queries.sql` - 5 аналітичних SQL-запитів (Q1-Q5), які доводять здатність схеми відповідати на всі 5 бізнес-питань.
- `src/run_sr12.py` - скрипт розгортання схеми, генерації 600 інцидентів (`seed = 42`), перевірки запитів та візуалізації.
- `docs/scheme.mmd` та `sr12_star_schema.png` - ER-діаграма зіркової схеми.
- `docs/star_schema_spec.md` та `terminal_sr12_proof.png` - результати виконання запитів у DuckDB.

## Запуск
```powershell
pip install -r requirements.txt
python src/run_sr12.py
```
